# Contributing

Das Repository ist privat. Aenderungen erfolgen ueber kleine, fachlich klar abgegrenzte Pull Requests.

## Vor einer Aenderung

1. Keine Zugangsdaten, personenbezogenen Inhalte oder erzeugten Briefings hinzufuegen.
2. Aenderungen an Authentifizierung, Token-Speicherung und Google-Scopes besonders pruefen.
3. AI-Ausgaben nicht als autoritative Datenquelle behandeln.

## Lokale Pruefung

```bash
npm run lint
npm run build
npm audit
```

Beschreibe in jedem Pull Request Zweck, Sicherheitsauswirkung, Testschritte und betroffene Google-Scopes.
