# PCG Agent Skills

Skills are reusable procedures. They describe how the agent should work with the OKF memory and Workspace sources; they are not project facts or task storage.

## Core Skills

- [OKF Memory Curation](okf-memory-curation.md) - Convert current evidence into structured OKF concepts.
- [Workspace Context Ingestion](workspace-context-ingestion.md) - Collect and prioritize Drive, Gmail, Calendar, Chat and Tasks.
- [Task State Reconciliation](task-state-reconciliation.md) - Treat Google Tasks as the authoritative task state.
- [David One-on-One Preparation](david-one-on-one-preparation.md) - Build every David 1:1 agenda from the dedicated task.
- [Daily Management Briefing](daily-management-briefing.md) - Produce the daily management update and deliver it.
- [Project and Customer Status](project-and-customer-status.md) - Keep project execution separate from account context.
- [Chat Command Safety](chat-command-safety.md) - Safely classify and execute Chat instructions.
