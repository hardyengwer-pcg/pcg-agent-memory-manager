# Skill: David One-on-One Preparation

## Purpose

Maintain a complete, current agenda for Hardy's 1:1 meetings with David.

## Canonical Agenda Source

The open Google Task `Besprechung David` is the permanent agenda container. Its title and full note must always be considered.

## Procedure

1. Read the complete `Besprechung David` task and note.
2. Match each topic against current OKF concepts, Tasks, Calendar events, Chat and Mail.
3. Remove topics that are explicitly completed or obsolete.
4. Add current status, decision needed, owner and source link where available.
5. Present the result as agenda points for the next David 1:1.

## Guardrails

- Do not create a separate Task for an agenda point unless independent preparation is required.
- Do not replace the task note automatically without preserving existing topics.
- Keep confidential personnel topics separate from customer project topics.
